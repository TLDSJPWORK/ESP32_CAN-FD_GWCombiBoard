# ソフトウェアについて

[双方向・全通過Gatewayサンプル](PassThroughGateway/README.md)を収録しています。ESP32 Dev Module向けのコンパイル・書き込み・起動と、通常CAN／CAN FDの双方向転送を2026-10-18に確認しました。試験条件（Pi側サンプル点80%、確認用フレームによる末尾受信の回収）と確認範囲はサンプルREADMEを参照してください。

MCP2518向けドライバ・ライブラリを使用する際は、[仕様書のGPIO割当](../docs/hardware.md)を設定してください。J9とJ10はSPI信号が別配線です。ライブラリが任意ピンや複数のSPI接続を扱えるか確認してください。

動作確認範囲は[組立ガイド](../docs/assembly.md#ソフトウェアと通信確認)を参照してください。
