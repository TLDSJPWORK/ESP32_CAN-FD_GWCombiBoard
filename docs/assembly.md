# 組立・動作確認ガイド

販売品はDB9コネクタ実装済み基板1枚です。ESP32、CAN FDモジュール、その他のコネクタ、電源部品、表示器、筐体は別途用意してください。

## 必要な部品

| 部品 | 数量・用途 |
|---|---|
| ESP32-DevKitC-32E／ESP32-DevKitC-VE／AE-ESP32-WROOM-32E-MINI | いずれか1枚 |
| CAN FDモジュール JP-WORKS-002 | 1チャンネルにつき1枚、最大2枚 |
| 接続用ヘッダ・ソケット | ESP32とCANモジュールの構成に合わせて用意。[端子寸法](hardware.md)を参照 |
| SSD1306表示器・Monitor用配線 | 表示器を使用する場合 |
| BP5293-50 | 外部12Vから5Vへ降圧する場合 |
| 外部電源用端子台・配線 | 外部電源を使用する場合 |
| 上下筐体・固定部品 | 筐体に収める場合。[筐体資料](../mechanical/README.md)を参照 |

対応部品の商品リンクは[README](../README.md#特徴)に掲載しています。

## 部品の取付方向

![ESP32とCAN FDモジュール2枚を取り付けた状態](images/assembly-photo.jpg)

ESP32のUSB端子はDB9と反対側に向けます。ESP32はJ1・J2・J5のうち使用するボードに対応する位置に合わせ、3V3・5V・GNDと端子番号を確認してください。CANモジュールの8ピン側はJ9・J10、CAN側はJ3（Ch1）・J4（Ch2）に接続します。

写真ではMonitor端子から4本の配線を表示器へ引き出しています。DC/DCは未実装です。

## 組立手順

1. 電源を外し、[接続表](hardware.md)と基板のシルクを確認します。
2. 使用するヘッダ・ソケットなどを、部品の端子番号と基板側の番号を合わせてはんだ付けします。DB9は販売時に実装済みです。
3. はんだブリッジ、電源極性、電源とGND間の意図しない短絡がないことを確認します。
4. CANモジュールの動作電圧ジャンパを3.3Vに設定し、ESP32とCANモジュールを取り付けます。
5. 各CANバスの両端にあるモジュールで120Ω終端を有効にします。JP-WORKS-002は2極スイッチSW1で切り替えます。中間点では終端を無効にします。
6. 表示器を使用する場合は、J6の1=GND、2=5V、3=GPIO22、4=GPIO21に合わせて配線します。表示器の端子順を合わせて接続してください。

## 給電と書き込み

USB給電と外部電源は併用しない前提です。写真の使用例はUSB給電を想定しています。ソフトを書き込む際も外部電源を外してください。

外部12Vを使用する場合はBP5293-50のpin 1（VIN）をJ7 pin 1、pin 2（GND）をJ7 pin 2、pin 3（VOUT）をJ7 pin 3に接続します。J8は1=12V、2=GNDです。DB9からの給電は[固有のピン配列](hardware.md)を確認してください。

外部12V給電の実測結果は未記録です。初回はESP32とCANモジュールを外し、電流制限付き電源で入力極性とJ7 pin 3–pin 2間の5Vを確認します。電源を切ってモジュールを取り付け、再給電後の5V・3.3V、消費電流、発熱、起動を確認してください。

## ソフトウェアと通信確認

本基板専用の動作確認済みサンプルは同梱していません。使用するMCP2518向けドライバ・ライブラリで、[チャンネルごとのGPIO割当](hardware.md#can-fdモジュールの接続gpio割当)を設定してください。J9とJ10はSPI信号が別配線です。

通常CANはCh1・Ch2とも動作実績がありますが、速度・使用ソフト・相手機器などの条件は未記録です。CAN FD、2系統同時通信、ゲートウェイ転送の動作実績は未確認です。

## 筐体に収める場合

![筐体に収めた使用例](images/enclosure-photo.jpg)

SSD1306表示器用の窓があります。この使用例はUSB給電のために筐体の一部を切断し、ESP32のUSB端子へケーブルを挿せるようにしています。写真のUSB側の開口は追加加工によるものです。

写真の追加部品・ケーブル・筐体は販売品に含まれません。公開STLとの版一致、印刷条件、固定ねじは[筐体資料](../mechanical/README.md)を参照してください。
