# 組立・動作確認ガイド（草案）

## 部品を準備する

コネクタの購入型番と取付方向の写真は整備中。端子数・ピッチは[仕様書](hardware.md)を参照する。
保存済みBOMはU1の情報が欠けているため、購入リストとしては整備中。

確認済みの購入対象はESP32-DevKitC-32E×1、JP-WORKS-002 CAN FDモジュール×1〜2、外部12V給電を使う場合はBP5293-50×1。表示器を使う場合はSSD1306対応品を別途用意する。基板以外は同梱しない。

CAN FDモジュールの動作電圧ジャンパを3.3Vに設定する。終端は各CANバスの両端にだけ設定する。外部電源での動作確認は12Vから開始し、USB給電は同時に接続しない。BP5293-50の向きは実装前に資料と照合する。

## 組立手順案

1. 販売品の基板リビジョンと回路図を照合する。
2. 【要確認：実装部品、はんだ付け順、コネクタの表裏・向き】に従って実装する。
3. 電源を接続する前に、電源極性と短絡の有無を確認する。
4. DC/DCの端子番号と給電経路を確認する。
   BP5293-50のpin 1（VIN）→J7 pin 1、pin 2（GND）→J7 pin 2、pin 3（VOUT）→J7 pin 3を対応させる。外部入力はまず12Vで確認し、USB給電と併用しない。
5. ESP32と各モジュールを【要確認：取付方向図】に従って装着する。
6. 【要確認：検証済み書き込み環境とサンプル】を使用する。
7. 各チャンネル単独の送受信を確認してから、2系統動作を確認する。

## 確認結果

[検証記録](validation.md)に基板リビジョン、モジュール型番、電源、速度、ソフトウェア版を記録する。
USBと外部電源は併用しない。DB9の配列は[仕様書](hardware.md)を参照する。各バスでモジュールが端点にある場合は120Ω終端を有効にし、中間点では無効にする。

## 初回給電の順序（未実機検証）

1. 基板単体の導通・短絡検査を完了する。
2. ESP32とCANモジュールを外した状態でDC/DCを実装し、端子番号と入力極性を確認する。
3. USBを外し、電流制限付き電源で12Vを入力する。J7 pin 3–pin 2間の出力が5Vであることを測定し、異常があれば直ちに切る。
4. 電源を切ってESP32とCANモジュールを装着する。CANモジュールの動作電圧は3.3Vにする。
5. 12Vで再給電し、5V・3.3V・消費電流・ESP32起動を記録する。
6. ソフトを書き込む際は外部電源を外す。検証済みサンプルはまだ用意していないため、通信試験の成功は未確認。

Monitor端子は5Vを供給する。表示器の電源許容範囲とI2C信号のプルアップ電圧がESP32に適合することを確認してから接続する。
