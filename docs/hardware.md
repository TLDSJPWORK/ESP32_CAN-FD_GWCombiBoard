# ハードウェア仕様

本基板に接続する部品と端子配列をまとめています。販売内容物はDB9コネクタ実装済みの基板1枚です。ESP32、CAN FDモジュール、表示器、DC/DCなどは用途に応じて別途購入・実装することを想定しています。実物の動作確認範囲は[検証状況](validation.md)を参照してください。

| 項目 | 設計上の情報 |
|---|---|
| ツール | KiCad 9.0 |
| 銅箔層 | F.Cu / B.Cu |
| 基板厚 | 1.6 mm |
| 設計外形 | 94×85 mm |
| 対応ESP32 | ESP32-DevKitC-32E／ESP32-DevKitC-VE／AE-ESP32-WROOM-32E-MINIのいずれか1枚 |
| 基板表記 | Ch1、Ch2、Monitor、5V、12V、GND |

5V・12Vは設計上の表記であり、入力許容範囲や同時給電可否を示すものではございません。

## 対応モジュールと給電

対応部品の商品リンクは[README](../README.md#特徴)を参照してください。

- CAN FDモジュール：MCP2518 + MCP2562FD CAN FD Busモジュール、JP-WORKS-002（SKU10019）。1チャンネルにつき1枚、最大2枚を接続します。
- モジュールの動作電圧ジャンパは3.3Vに設定してください。終端抵抗は60Ω抵抗2本による合計120Ωで、2極スイッチSW1で切り替えます。各CANバスの両端で有効にし、設定方向はモジュールの表示と資料を確認してください。
- 表示器：SSD1306対応の有機ELディスプレイをJ6（Monitor）に接続できます。
- 外部給電用DC/DC：ROHM BP5293-50（秋月111188）。12Vから5Vへ降圧して給電する構成に使用します。部品定格は入力7〜26V、出力5V、最大1Aです。これは部品の定格であり、組立済み基板全体の動作保証範囲ではございません。
- 外部電源使用時はESP32のUSB給電を併用しない前提です。書き込み時は外部電源を外してUSB給電を使用して下さい。

参考：[CAN FDモジュール商品資料](https://www.switch-science.com/products/10019)、[BP5293-50商品資料](https://akizukidenshi.com/catalog/g/g111188/)。各端子の接続は以下の表を参照してください。

| 参照番号 | 端子の構成 | 用途・ピン配列 |
|---|---|---|
| J1・J2・J5 | J1・J5：1×19、J2：1×16、いずれも2.54 mmピッチ | ESP32開発ボードを接続します。3V3・5V・GNDと端子番号を合わせて取り付けます。 |
| J9・J10 | 1×8、2.54 mmピッチ | CAN FDモジュールのSPI・給電端子です。ピン配列とGPIO割当は下表を参照してください。 |
| J3（Ch1）・J4（Ch2） | 1×3、2.54 mmピッチ | CANモジュールのCAN側端子です。1=CAN-H、2=CAN-L、3=GNDです。 |
| J6（Monitor） | JST XH 4ピン | SSD1306表示器用です。1=GND、2=5V、3=GPIO22、4=GPIO21です。表示器側の端子順も確認してください。 |
| J7 | 1×3、2.54 mmピッチ | BP5293-50の接続部です。1=12V入力、2=GND、3=5V出力です。 |
| J8 | 2極端子台、5 mmピッチ | 外部電源入力です。1=12V、2=GNDです。 |
| DB1（DB9・実装済み） | XDDB-1809-0816 | 販売時に実装済みです。2系統のCAN信号と外部電源をまとめて接続します。下記のDB9ピン配列を参照してください。 |

寸法は設計値です。組立方向は[組立ガイド](assembly.md)の写真を参照してください。

## CAN FDモジュールの接続・GPIO割当

| ピン | モジュール側の信号 | J9（Ch1） | J10（Ch2） |
|---|---|---|---|
| 1 | SCK | GPIO32 | GPIO27 |
| 2 | CS | GPIO26 | GPIO14 |
| 3 | SDO（ESP32のMISO） | GPIO19 | GPIO13 |
| 4 | SDI（ESP32のMOSI） | GPIO18 | GPIO12 |
| 5 | INT | GPIO25 | GPIO15 |
| 6 | GND | GND | GND |
| 7 | 5V | 5V | 5V |
| 8 | 3.3V | 3V3 | 3V3 |

J9とJ10のSPI信号は別配線です。使用するドライバ・ライブラリで、それぞれのGPIO割当を設定してください。GPIO12・15はESP32の起動設定にも関わるため、J10側のモジュールを装着した状態で起動を確認してください。

## DB9のピン配列

DB9には2系統のCAN信号と外部電源を配置しています。本基板固有の配列のため、接続先の配列と照合してください。

|DB9ピン|信号|
|---|---|
|1|J4側CAN-L|
|2|J3側CAN-L|
|3|J3側GND|
|4|未接続|
|5|共通GND|
|6|J4側GND|
|7|J3側CAN-H|
|8|J4側CAN-H|
|9|外部電源入力（+12V表記）|
|10・11（固定端子）|共通GND|

J3/J4のpin 3は基板上で共通GNDへ直接接続されず、CANモジュールを介して共通GNDにつながります。DB9のみ実装した販売状態では、DB9 pin 3/6と共通GNDが非導通でも、それだけで不良とは判断しません。

参考：[CAN-FD_Board回路図](https://github.com/TLDSJPWORK/CAN-FD_Board/blob/main/docs/CAN-FD_Board.pdf)

## BP5293-50の接続

ROHMデータシートRev.C（2016-10-13）2ページの端子説明は1=VIN、2=GND、3=VOUT。基板J7の1=12V入力、2=GND、3=5V出力に対応します。実装時は部品の端子番号とPCBパッド番号を合わせてください。

表示器・ESP32・CANモジュールを含む総負荷電流と発熱を確認してください。

出典：[ROHM BP5293データシート](https://akizukidenshi.com/goodsaffix/BP5293_DataSheet_J_VerC_161013.pdf)。取付時は周囲の部品や筐体との干渉も確認してください。
